## 0. 设计原则

### 0.1 图标规范

全项目统一使用 **Lucide** 图标库（MIT 协议，与 antd 风格协调）。
禁止使用 emoji 作为 UI 图标（跨平台渲染不一致）。

| 用途 | Lucide 图标名 | 说明 |
|------|--------------|------|
| 消息导航 | `Mail` | 侧边栏"消息" |
| 市场导航 | `Store` | 侧边栏"消息市场" |
| 设置导航 | `Settings` | 侧边栏"设置" |
| 刷新 | `RefreshCw` | 顶栏刷新按钮 |
| 搜索 | `Search` | 搜索框前缀 |
| 连接在线 | `Circle` (fill: green) | 状态指示灯 |
| 连接中 | `Circle` (fill: amber) | 状态指示灯 |
| 断开 | `Circle` (fill: red) | 状态指示灯 |
| 删除 | `Trash2` | 右键菜单、操作条 |
| 已读 | `CheckCheck` | 标已读 |
| 未读 | `Mail` (with dot) | 标未读 |
| 复制 | `Copy` | 复制按钮 |
| 展开/折叠 | `ChevronLeft` / `ChevronRight` | 侧边栏 |
| 外部链接 | `ExternalLink` | 浏览器打开 |
| 眼睛（显示） | `Eye` | SPT 展开 |
| 眼睛（隐藏） | `EyeOff` | SPT 遮罩 |
| 警告 | `AlertTriangle` | 横幅/Toast |
| 错误 | `XCircle` | 横幅/Toast |
| 成功 | `CheckCircle2` | Toast |
| 关闭 | `X` | Banner 关闭、弹窗关闭 |

### 0.2 焦点样式（键盘导航）

桌面端重度依赖键盘操作，所有交互元素必须有清晰的 `:focus-visible` 样式：

```css
/* 通用焦点环 */
:focus-visible {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;
  border-radius: var(--radius-sm);
}

/* 列表项焦点态（消息列表、侧边栏导航） */
.list-item:focus-visible,
.sidebar-item:focus-visible {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: -2px;  /* 内缩，与选中态视觉一致 */
  background: var(--color-bg-hover);
}

/* 输入框焦点态 */
input:focus-visible {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 2px var(--color-primary-bg);
}

/* 按钮焦点态 */
button:focus-visible {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;
}
```

### 0.3 设计原则总览

| 原则 | 说明 |
|------|------|
| **品牌一致** | 主色 `#B300B3`，与 WxPusher 全线产品统一 |
| **简洁克制** | 避免 AI 卡片 UI、过度装饰；信息流为主 |
| **呼吸感** | 间距 12-16px 级别，卡片圆角 10-12px，轻边框/微阴影 |
| **双模适配** | 所有页面同时支持浅色/深色模式，跟随系统 |
| **大屏优先** | 双栏布局，键盘导航，桌面端操作习惯 |

### 1.3 标题栏 & 顶栏

**macOS（hiddenInset）**：
- 交通灯（红绿黄）在左侧，距左 16px、距顶 16px

**Windows（titleBarOverlay）**：
- 系统标题栏保留（最小化/最大化/关闭），叠加自定义区域
- 自定义区域颜色：浅色 `#FFFFFF`、深色 `#1E1E1E`

**顶栏布局**：

### 2.2 状态变化

| 状态 | 二维码区 | 底部提示 |
|------|---------|---------|
| 初始（未勾选协议） | 不显示二维码，显示协议勾选框 | "请先同意用户协议" |
| 勾选协议后 | 加载中 spinner | "正在连接服务..." |
| WS 连接中 | 加载中 spinner | "正在连接服务..." |
| 二维码加载完成 | 显示二维码 | "请使用 WxPusher App 或微信扫码" |
| 倒计时 ≤ 30 秒 | 二维码正常 | "即将过期，可点击刷新"（橙色） |
| 已过期 | 二维码变灰 | "已过期，点击刷新"（红色按钮） |
| 网络异常 | 二维码区 + 错误图标 | "网络异常，请检查网络连接" |
| 扫码成功 | 全屏 spinner | "登录成功，正在进入..." |

### 2.3 交互细节

- **协议勾选**：默认不勾选，必须勾选才能继续。勾选后立即并行触发：① 请求通知权限 ② 建立 WS ③ 加载二维码
- **二维码尺寸**：200 × 200 px，白色背景，居中显示
- **刷新按钮**：倒计时 ≤ 30 秒时出现，点击重新调用 `create-login-qrcode`
- **下载链接**：底部紫色文字链接（`var(--color-text-link)`），点击用系统浏览器打开下载页
- **整体居中**：垂直水平居中，卡片容器最大宽度 400px，圆角 12px，微阴影
- **背景对比**：登录页背景使用 `var(--color-bg-page)`（`#FAFBFE`），卡片使用 `var(--color-bg-container)`（`#FFFFFF`），通过阴影 `var(--shadow-lg)` 区分层级（两色差值小，阴影是主要区分手段）
- **键盘焦点**：协议勾选框、刷新按钮、下载链接均有 `:focus-visible` 焦点环

### 3.2 列表项设计

**尺寸**：高度 84px（名称行 21px + 摘要 2 行 39px + 上下 padding 24px），宽度自适应列表栏

**结构**：

```
┌──────────────────────────────────────────────┐
│  ● 发送方名称                    2 分钟前     │  ← 左侧 8px 主色圆点(未读) + 名称 + 相对时间
│    消息摘要内容消息摘要内容消息摘要内容消...   │  ← 2 行省略
└──────────────────────────────────────────────┘

已读态：无左侧圆点
未读态：左侧 8px 主色圆点（--color-primary）+ 微阴影
选中态：背景 --color-bg-active
hover 态：背景 --color-bg-hover + 显示 sourceUrl 气泡
```

**样式细节**：
- 发送方名称：`font-size: 14px`，`font-weight: 500`，`color: var(--color-text-primary)`
- 时间：`font-size: 12px`，`color: var(--color-text-tertiary)`
- 摘要：`font-size: 13px`，`color: var(--color-text-secondary)`，2 行省略
- 未读圆点：`width: 8px`，`height: 8px`，`border-radius: 50%`，`background: var(--color-primary)`，`box-shadow: 0 0 6px rgba(179,0,179,0.4)`
- 已读：无圆点（透明占位，保持对齐）
- 分割线：`height: 1px`，`background: var(--color-divider)`

## 16. 动画与过渡规范

缓动曲线定义在 `design-tokens.css` 中，对应关系：
- `--easing-standard` = `cubic-bezier(0.4, 0, 0.2, 1)` — 通用过渡
- `--easing-decelerate` = `cubic-bezier(0.0, 0, 0.2, 1)` — 进入动画
- `--easing-accelerate` = `cubic-bezier(0.4, 0, 1, 1)` — 退出动画

| 场景 | 动画 | 时长 | 缓动变量 |
|------|------|------|----------|
| 侧边栏折叠/展开 | 宽度过渡 | `var(--duration-base)` (250ms) | `var(--easing-standard)` |
| 列表项 hover | 背景色过渡 | `var(--duration-fast)` (150ms) | `var(--easing-standard)` |
| Toast 出现 | 淡入 + 上移 10px | `var(--duration-base)` (250ms) | `var(--easing-decelerate)` |
| Toast 消失 | 淡出 | 200ms | `var(--easing-accelerate)` |
| 弹窗打开 | 缩放 0.95→1 + 淡入 | `var(--duration-base)` (250ms) | `var(--easing-decelerate)` |
| 弹窗关闭 | 缩放 1→0.95 + 淡出 | 200ms | `var(--easing-accelerate)` |
| 连接状态灯切换 | 颜色过渡 | 300ms | `var(--easing-standard)` |
| 骨架屏 shimmer | 背景位置循环 | 1.5s infinite | `linear` |

## 17. 暗色模式适配要点

- 所有颜色通过 CSS 变量引用（`var(--color-xxx)`），深色模式在 `html.dark` 下覆盖
- antd 组件通过 `ConfigProvider` 的 `theme.darkAlgorithm` 切换
- WebView 通过 preload 注入 `data-prefers-color-scheme='dark'` 属性
- 重点检查：主色在深色背景下的对比度 ≥ 4.5:1（WCAG AA）
- 避免纯黑背景，使用 `#121212` / `#1E1E1E` 柔和深色

## 18. 响应式与虚拟滚动

### 18.1 响应式断点

桌面端窗口可调整大小，需处理极端尺寸：

| 窗口宽度 | 布局策略 |
|----------|---------|
| ≥ 1600px | 双栏正常，列表栏上限 600px，详情区自适应居中（max-width 960px） |
| 1200-1599px | 双栏正常显示 |
| 900-1199px | 双栏，列表栏取最小 280px |
| < 900px | 不允许（窗口 minWidth 限制） |

侧边栏折叠态（56px）在窗口较窄时自动激活，为内容区腾出空间。

### 18.2 虚拟滚动（react-virtuoso）

消息列表使用 `react-virtuoso` 实现虚拟滚动，需注意：

- **滚动位置恢复**：从详情页返回列表时，恢复之前的滚动位置（store 中记录 `scrollOffset`）
- **加载更多**：滚动到底部 100px 内自动触发 `loadMore()`，底部显示 loading spinner
- **键盘导航**：`↑/↓` 键切换聚焦项时，自动滚动确保聚焦项可见（`scrollIntoViewIfNeeded`）
- **新消息插入**：WS 推送的新消息插入列表顶部，若用户不在顶部则显示"有新消息"浮动按钮，点击滚动到顶部
- **overscan**：设置 `overscan={200}px`，保证快速滚动时无空白闪烁
